# 5分の操作確認（人間による評価は未実施）

判定：**未実施 / HOLD**。以下は操作手順であり、合格記録ではありません。
目的は「専門用語を覚えず、次に何をすればよいかわかるか」の確認です。途中で迷ったら、その言葉や画面を記録してください。無理に先へ進む必要はありません。

準備：Node 22.12以上または24、PR #1のMCCフォルダ。初回インストール時間は5分に含めません。ターミナルはWindowsのPowerShell 7を推奨します。

1. **開く** — MCCフォルダでターミナルを開き、`npm.cmd ci`、次に `npm.cmd run dev -- --host 127.0.0.1` を実行。表示されたURLを開きます。「今日は何をしたいですか？」が見えるか確認します。
2. **目的を伝える** — `ゲームの自律テストを準備したい` と入力。候補を選び、「準備」「実行する場所」「期待する結果」を読んでください。いま行うのはゲームの実行か、計画作成か、自分の言葉で説明できるか確認します。
3. **コピーする** — 「起動コマンドをコピー」を押し、メモ帳へ貼り付けます。この確認では実行しません。表示されたコマンドと同じか確認します。
4. **診断を読む** — 別のターミナルを同じMCCフォルダで開き、下記を実行。画面の「システム診断」を開き「診断JSONを読み込む」で生成ファイルを選びます。「必要ファイルを検出」が実行成功を意味しないこと、不足時に何を確認すればよいかが読み取れるか確認します。
5. **困ったときを試す** — 結果欄で練習として「エラーになった」を選びます。次にすることがわかるか確認。別の目的に切り替えると「未実行」に戻るか確認します。終了後はサーバーのターミナルでCtrl+C。

```powershell
node scripts/first-run-doctor.mjs --projects-root "C:\Dev\Projects" > first-run-report.json
```

リポジトリを別の場所に置いた場合はパスを変更します。4リポジトリが揃っていなくても「不足」が正しく出れば診断の失敗ではありません。PowerShell 5でJSONの文字コードエラーが出る場合は、出力を `| Set-Content -Encoding utf8 first-run-report.json` に変えて再作成してください。
